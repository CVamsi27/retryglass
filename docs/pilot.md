# Retryglass integration trial

Choose a non-production change in an independently maintained repository. The trial task is to run a corrected and broken synthetic processor with one declared effect, then keep one verified exported crash-point test.

Use the [GitHub starter](../README.md#try-the-starter-without-cloning) and prepare OrbStack using the README. Keep the same persisted job and business key. Compare the test with your existing fault/retry check for that effect. Record full-sweep and selected-point costs separately.

Record the pinned version and runtime, cold download time, hands-on setup and assistance, machine runtime, and the concrete result or action. Compare equivalent checks on the same fixture. Record whether the check enters the normal workflow and whether it runs on a later relevant change. Record observations at 14, 30 and 90 days. A period without a relevant change remains unobserved.

The [opt-in issue form](https://github.com/CVamsi27/retryglass/issues/new?template=integration-trial.yml) accepts sanitized summaries and synthetic reproductions. Share private repository details only with consent. The [portfolio trial record](https://github.com/CVamsi27/developer-pain-lab/blob/HEAD/docs/adoption-trials.md) tracks the current cohort and aggregates results.
